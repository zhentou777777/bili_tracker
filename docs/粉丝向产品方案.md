## 一、一句话结论

你提的三个方向里，**「开播提醒」和「动态查看」项目已经做出来了**（接手时踩过的坑都已修：动态接口下线、登录不可靠、主题换不了肤、直播卡崩溃）；**「弹幕」目前只是"借第三方页面"的轻量形态 —— App 内自研弹幕墙是空白**，这既是最大的缺口，也是粉丝向最有差异化的一块。

所以建议的前三步：**先让推送真的快 → 再做自研弹幕墙 → 再打磨动态时间线。**

## 三、技术可行性复核（先给结论，再说坑）

### 1. 开播推送：WebSocket 不是答案，"公开 REST + 服务端兜底"才是

- 你建议的 WS 长连，在**桌面常驻程序**里合理；在**手机 App** 里价值有限：App 一进后台，WS 很快被系统掐断，**反而比轮询更不可靠**，还更耗电。监听 `PREPARING`（下播）同理。
- 项目用的 `get_status_info_by_uids` 是**公开接口**（实测无需 Cookie、可批量传 uid）。它最大的好处是：**服务端可以用它做兜底，而服务端完全不需要你的账号凭据** —— 这正好和项目两条红线（Cookie 只进本机 Keystore、服务端零代理）天然兼容。
- **结论：保持 REST 轮询，把服务端兜底真正部署起来。**`server/worker.js` 里 `scheduled` 每 10 分钟轮询公开直播接口的逻辑已经写好，只是没部署。这是"比官方快"唯一现实、且合规成本最低的实现路径。

### 2. 自研弹幕：可行，但**分两档**做（强烈建议从轻量档起步）

B 站直播弹幕是**非官方长连接协议**，完整实现对移动端是一次"中等偏大"工程：

**完整档（能拿全：弹幕 / 礼物 / SC / 上舰）** 需要：
1. `getDanmuInfo` 拿 `token` + `host_list`（wss 地址）；短房间号要先转 `real_room_id`；
2. 建 WS → 发**握手包**（`protover=3` = brotli 压缩 + 自定义包头）→ 每 30s 心跳；
3. 解压（brotli）→ 解析 **protobuf**（不是 JSON）→ 分派 `DANMU_MSG` / `SEND_GIFT` / `SUPER_CHAT_MESSAGE` / `GUARD_BUY` / `INTERACT_WORD`。

- Dart 侧要新增 `web_socket_channel` + brotli 解码 + protobuf 解析。`lib/core/` 目前**只有 HTTP 传输**，等于要新增一整个传输层。
- 移动端硬限制：**只有前台能看**（后台 WS 必被掐），所以形态只能是"开播后一键进弹幕墙"，不可能常驻。悬浮窗同理，只能在 App 前台。

**轻量档（建议先做，1~2 天量级）**：
- 用**弹幕历史轮询**接口取最近若干条弹幕，做成滚动弹幕墙（核心是"简洁、快、能高亮关键词"）。
- 优点：**纯 HTTP**，可直接复用现有 `core/http` + 规则外置（端点写进 `assets/rules/platforms.json`）+ 现有风控退避，**不动架构**。
- 代价：秒级延迟、拿不到礼物/SC 全量类型。
- ⚠️ **动手第一步必须先用探针实测端点存活** —— 本项目吃过"接口整条下线"的亏（坑清单第 8 条：旧动态接口 404，参数怎么调都没用）。端点死了就直接上完整档。

**一句话：轻量档验证需求，完整档再做实时与礼物/SC。**

### 3. 动态：已无技术障碍

新接口 + WBI 签名 + `buvid3` 都已实现并实测通过（探针 40/40）。剩下的纯属**产品形态问题**（时间线流、筛选、收藏），不是协议问题。

### 4. 官方通道：粉丝向**用不上**，别再投时间

- 直播开放平台要**主播**用身份码授权 → 与"服务观众"冲突；
- 官方 OAuth 2.0 要企业资质入驻，且**只能换 `access_token`、换不到 `SESSDATA`**，而关注列表/动态/观看历史全靠 SESSDATA → 做了也达不到目的。

## 七、红线与风险（沿用项目既有约定）

- **两条红线不动**：Cookie 只进本机 Keystore / Keychain；服务端零代理、推送中继只转发字段白名单内的摘要。
- **风控**：`code:-352`（账号侧限流）、HTTP `412`（缺 `buvid3`）、WBI 签名；弹幕 WS 还要 `token`，且协议随时可能改。
- **已知坑照旧遵守**：增量编译可能假成功（看 Gradle 耗时 + 拆包核对）、改规则必提 `version`、深链要 Dart 与清单两边都改、`CrossAxisAlignment.stretch` 别放进高度无界的容器。
- **合规**：全部走非官方接口，不上架滥用、不过度爬取；**弹幕数据默认不落库**（只有统计类才增量落 SQLite）；遇到验证码请重新登录或降频。
