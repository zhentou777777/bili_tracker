# 文档目录

代码在上一级目录。这里放的是**开发过程文档**，不是给使用者看的 —— 想下载安装，回上一级看 `README.md`。

## 先读哪份

| 你想知道 | 读这份 |
|---|---|
| 现在做到哪一步了、还差什么 | **`交接总结.md`** ← 从这份开始 |
| 为什么会变成现在这样、踩过哪些坑 | **`交接文档.md`**（权威版，最长也最全） |
| 怎么把它编译出来 | `编译说明.txt` |

## 两个阅读约定

**1. 文档里的相对路径按「仓库根目录」写。**
比如 `交接文档.md` 里写「见 `docs/archive/HANDOVER.md`」，指的是仓库根目录下的那个位置，不是相对本文档的位置。这是刻意不改写的 —— 一旦批量改写，这些文档就不再是「当时那份原始记录」了。

**2. `archive/` 里的东西是历史证据，不是当前说明。**
其中被后续实测推翻的结论**故意保留原文**，方便追溯「当时为什么这么判断」。要看当前结论，读 `交接文档.md`。
